# منصة التداول الآلي (OKX)

منصة شخصية تتصل بحساب OKX (Spot) وتنفذ صفقات تلقائيًا بناءً على استراتيجية:
السعر > VWAP + ضغط شراء في دفتر الأوامر + حجم أعلى من المتوسط (دخول) ,
جني ربح 10% أو وقف خسارة 1% (خروج).

## 1. تجهيز مفاتيح OKX

1. من حسابك في OKX: **API Management > Create API Key**.
2. أعطِ المفتاح صلاحية **Trade** فقط. **لا تفعّل Withdraw إطلاقًا**.
3. قيّد المفتاح بعنوان IP جهازك إن أمكن.
4. انسخ `backend/.env.example` إلى `backend/.env` واملأ:
   - `OKX_API_KEY`, `OKX_API_SECRET`, `OKX_API_PASSPHRASE`
   - `APP_PASSWORD` (كلمة سر الدخول للوحة، غيّرها عن القيمة الافتراضية)
   - `SESSION_SECRET` (نص عشوائي طويل)
   - اترك `TRADING_MODE=paper` في البداية دائمًا.

للتجربة على حساب OKX Demo Trading بدل الحقيقي: فعّل Demo Trading من OKX، أنشئ مفتاحًا من نفس واجهة Demo، وضع `OKX_DEMO=true`.

## 2. تشغيل الـ Backend

```bash
cd backend
python -m venv venv
venv\Scripts\activate      # على ويندوز
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

## 3. تشغيل الـ Frontend

```bash
cd frontend
npm install
npm run dev
```

افتح `http://localhost:5173` على نفس الجهاز.

## 4. الوصول من الجوال

بعد تشغيل `npm run dev`، سيطبع Vite رابط شبكة مثل:
`http://192.168.x.x:5173`

افتح هذا الرابط من متصفح الجوال (بشرط أن يكون الجوال متصلاً بنفس شبكة الواي فاي التي عليها جهاز الكمبيوتر). لا حاجة لأي إعداد إضافي — الفرونت يمرر طلبات `/api` و`/ws` تلقائيًا للـ backend على نفس الجهاز.

للوصول من خارج الشبكة المنزلية (مثلاً بيانات الجوال) يلزم حل إضافي مثل Tailscale أو نشر المنصة على VPS — غير مُفعّل حاليًا.

## 5. أول تشغيل

1. سجّل الدخول بكلمة السر من `APP_PASSWORD`.
2. راجع **الإعدادات**: الأزواج، نسب الربح/الخسارة، حجم الصفقة، حدود المخاطر.
3. من **لوحة التحكم**، اضغط **تشغيل البوت** (يبدأ تلقائيًا في وضع `Paper` — محاكاة بدون أموال حقيقية).
4. راقب صفحة **قرارات البوت** لترى سبب كل قرار دخول/رفض/خروج لحظيًا، وتأكد أن القرارات منطقية.
5. عندما تطمئن، فعّل **التحويل للتداول الحقيقي** من لوحة التحكم — من هذه اللحظة سينفذ البوت صفقات فعلية بأموالك على OKX.

## آليات الأمان المدمجة

- **Kill Switch**: يوقف أي صفقة جديدة فورًا (مع خيار إغلاق كل الصفقات المفتوحة).
- **حد خسارة يومي**: يوقف الدخول تلقائيًا إذا تجاوزت الخسارة اليومية النسبة المحددة في الإعدادات.
- **حد صفقات متزامنة** وحجم صفقة كنسبة من رأس المال، يُتحقق منهما قبل كل أمر شراء.
- **سجل قرارات كامل** لكل تقييم (`decision_log` في قاعدة البيانات + صفحة قرارات البوت).

## هيكل المشروع

- `backend/` — FastAPI + SQLite. اتصال OKX (REST موقّع + WebSocket عام)، محرك الاستراتيجية، إدارة المخاطر.
- `frontend/` — React + Vite + Tailwind. لوحة تحكم متجاوبة للجوال.
